# SHOAL

群れの中の1匹として、泳ぐ向きと位置で仲間を増やす3Dブラウザゲーム。

## 遊べる内容

- 沖縄のサンゴ礁、黒潮の外洋、相模湾の夜を舞台にした12ミッション。星評価・最高タイムを端末に保存。
- カツオの横断、イルカの包囲と交代攻撃、海鳥の急降下、定置網。岩の回避、海流と岩陰の弱い流れ。
- 追従、俯瞰、映画カメラ。自由遊泳、PNG撮影、エンドレス回遊の最高記録。
- 同じ魚群を取り合う60秒のAI対戦・オンライン1対1。分裂した場合は各陣営の最大のまとまりを数える。
- 海の環境音、仲間が増えた音、警戒音、成功・失敗音。音声はWeb Audioによる合成。

公開版: https://neconeco0306.github.io/shoal/

オンラインは「ふたりの海」で部屋を作成し、相手に6文字コードを伝える。無料サーバーの休止後は接続に約1分かかることがあります。

## 起動

Node.js 22.12以上を推奨。依存バージョンは固定。

```sh
npm ci --ignore-scripts
npm run dev
```

表示されたローカルURLを開く。公開ビルドは `npm run build`、確認は `npm run preview`。

## オンラインサーバー

```sh
npm run server
```

ローカル接続先は `ws://127.0.0.1:8787/play`。海図の「ふたりの海」で部屋を作り、相手が6文字のコードを入力すると開始。サーバーが移動・魚群・勝敗を計算し、クライアントからは操作量のみ送る。500匹、15Hz計算、約7.5Hzスナップショットを補間表示。同時進行は2試合まで。切断は試合終了、部屋は10分で破棄。再接続は新しい部屋で行う。

環境変数:

- `PORT`: サーバーの待受ポート（既定8787）。`0.0.0.0`で待受。
- `ALLOWED_ORIGINS`: 接続を許すフロントエンドのOriginをカンマ区切り。既定はlocalhostの開発・プレビュー用。
- `VITE_MULTIPLAYER_URL`: フロントエンドのビルド時に公開WebSocket URLを設定。HTTPSサイトでは `wss://` が必要。

`GET /health` は稼働状態を返す。人数制限、入力値検査、1KBメッセージ上限、送信頻度制限、heartbeat、切断時の中立化・部屋終了を実装。公開サービスの負荷試験や大規模運用を保証するものではない。

## 検証・調整

```sh
npm test
npm run typecheck
npm run build
npm run benchmark
```

`?debug` で調整パネルと読み取り専用 `window.__shoal()` を表示。`?debug&fish=1500` で計測用の匹数を指定。通常は端末の計算速度を開始前に測って匹数を選び、低FPS時に描画解像度を下げる。300匹以上では近隣計算をWeb Workerで最大15Hz更新し、操作・情報獲得・逃避・衝突・移動はメイン側の30Hz処理で維持する。Workerが利用できない場合は同期計算に戻る。プレイ途中で魚は減らさない。端末・発熱・他アプリの負荷によりフレームレートは変わる。
